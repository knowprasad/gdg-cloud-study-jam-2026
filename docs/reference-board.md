## Three active directions
- **Guild Clubhouse** (`clubhouse`): retained/default/preferred; neutral canvas, forest/sage surfaces, yellow actions, intact chapter identity and a selected-learner collectible pass with ten progress marks.
- **Campus Canvas** (`canvas`): warm neutral, Bhopal-led hierarchy; an arched ten-course collector updates a course lens on selection, with completion states drawn from the same demo profile.
- **Builders League** (`builders`): blue, VIT/Noida-led expressive typography; nearby-rival profile links, selected-row emphasis and a personal aside on the left of desktop standings. Phone layouts stack standings before the aside.

Cloud Expedition has been removed from the active preview registry. All three current concepts use the same 500 fictional participants, eight guilds, ten courses, routes, working lookup/filtering, self-hosted Manrope, Phosphor icons, dark mode and responsive header links. No bottom navigation tabs. The comparison is about presentation; mock scores and rankings do not settle pending competition rules.
